# pyCRAC Benchmarking and ML-Based RNA–RBP Motif Prediction

Benchmarking of pyCRAC v1.5.2 vs v2.0.0, and machine-learning motif prediction (Pysster, ClipGPS, DeepCLIP, MSipNet) on Nab3 and Ssd1 CRAC datasets.

## Repository structure

```
project_code/
├── data/
│   ├── nab3.tar.gz          # pyReadCounters GTF output for Nab3 (mapped read coordinates/counts)
│   ├── ssd1.tar.gz          # pyCalculateFDRs peak GTF for Ssd1 (FDR <= 0.05)
│   └── references/          # reference genome files — NOT included, see "Data setup" below
├── motif_prediction/
│   ├── Data_preparation/    # peak-interval to ML-dataset pipeline (Motif_pipeline.ipynb)
│   ├── Pysster/             # Pysster model training
│   ├── ClipGPS/             # ClipGPS training/tuning/evaluation
│   ├── MSipNet/             # MSipNet + RNA-FM embeddings
│   └── mutational_scans/    # DeepCLIP and Pysster mutational scanning
└── pycrac_benchmark/        # v1.5.2 vs v2.0.0 runtime benchmarking
```

## Data setup

### Included in this repo

Extract before use:

```bash
tar -xzf data/nab3.tar.gz -C data/
tar -xzf data/ssd1.tar.gz -C data/
```

- **`nab3.tar.gz`** — pyReadCounters GTF output for Nab3: mapped read coordinates, counts and genomic annotations, generated from a Novoalign (`.novo`) file against the R64-1-1.75 annotation.
- **`ssd1.tar.gz`** — pyCalculateFDRs peak GTF for Ssd1 (FDR ≤ 0.05), from Bayne et al., used directly for downstream analyses.

### Not included/download required

Raw sequencing files and reference genomes

**Nab3** (Esteban-Serna et al., 2025)
- Raw paired-end FASTQ (demultiplexed, UMI-annotated) and the `.novo` alignment file (generated by the Granneman lab) for GEO:**GSE276517**, replicate 2 of the parental PIC2–GFP/Nab3-HTF strain.
- Reference genome: *S. cerevisiae* R64-1-1 annotation GTF + genome FASTA + chromosome lengths file.

**Ssd1** (Bayne et al.)
- CRAC data (single-end): GEO accession **GSE159835**.
- Reference genome: *S. cerevisiae* EF4 annotation GTF  + genome FASTA (available from Bayne et al. supplementary materials)

### `data/references/`

Place downloaded reference files here, keeping datasets separate:

```
data/references/
├── GSE276517_Saccharomyces_cerevisiae.R64-1-1.75_1.2.gtf
├── GSE276517_Saccharomyces_cerevisiae.R64-1-1.75.fa
├── GSE276517_Saccharomyces_cerevisiae.R64-1-1.75.fa.tab
├── GSE276517_Saccharomyces_cerevisiae.R64-1-1.75_chr_lengths.txt
├── Saccharomyces_cerevisiae.EF4.74_SGDv64_CUTandSUT_withUTRs_noEstimates_antisense_intergenic_4xlncRNAs_final.pyCheckGTFfile.output.quotefix.gtf
├── Saccharomyces_cerevisiae.EF4.74.dna.toplevel.shortChrNames.fa
└── Saccharomyces_cerevisiae.EF4.74.dna.toplevel.shortChrNames.lengths"
```

Generate the chromosome-length files with pyCRAC once the FASTA is downloaded:

```bash
pyCalculateChromosomeLengths.py -f <genome.fa> -o <chrom_lengths.txt>
```

> **Note on relative paths:** scripts and notebooks in this repo reference reference/data files via relative paths set up for this exact directory layout. If a script errors with a missing file, check the path variables near the top of the script/notebook and point them at wherever you've placed the downloaded files.

## Pipeline

**Nab3**
1. Download raw FASTQ + `.novo` file (OpenNGS / GSE276517).
2. `pyReadCounters` with the R64-1-1.75 GTF → read-count GTF (equivalent to `data/nab3.tar.gz`).
3. `pyCalculateFDRs` (`-r 100`, FDR ≤ 0.05, 100 background iterations) → peak GTF.
4. `pyNormalizeIntervalLengths.py` → fixed-length intervals (50nt and 100nt tested).
5. `motif_prediction/Data_preparation/Motif_pipeline.ipynb` → labelled positive/negative FASTA datasets (see script for overlap removal / negative-sampling logic).
6. Train models: `motif_prediction/Pysster/Pysster_fit.py`, `motif_prediction/ClipGPS/custom_nab3_pipeline.sh`.
7. Benchmarking: `pycrac_benchmark/test.sh`, `test_timing.sh`.

**Ssd1**
Starts from the pre-existing `pyCalculateFDRs` output (FDR ≤ 0.05, `data/ssd1.tar.gz`). Steps 4–6 apply with the EF4.74 reference and 100nt/300nt intervals; use `custom_ssd1_pipeline.sh` for ClipGPS.

**Mutational scanning:** `motif_prediction/mutational_scans/ClipGPS` (built-in `scan.py`), `.../Pysster` (`pysster_scan.py`, adapted from ClipGPS), and DeepCLIP variant-prediction mode — see individual scripts.
