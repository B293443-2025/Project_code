# pyCRAC Benchmarking and ML-Based RNA–RBP Motif Prediction

Benchmarking of pyCRAC v1.5.2 vs v2.0.0, and machine-learning RNA-RBP binding prediction using Pysster, ClipGPS (unreleased), DeepCLIP and MSipNet on Nab3 and Ssd1 CRAC datasets.

## Repository structure

```
project_code/
├── data/
│   ├── nab3.tar.gz          # pyReadCounters GTF output for Nab3 (mapped read coordinates/counts)
│   ├── ssd1.tar.gz          # pyCalculateFDRs peak GTF for Ssd1 (FDR <= 0.05)
│   └── references/          # reference genome files — NOT included, see "Data setup" below
├── motif_prediction/
│   ├── Data_preparation/    # peak-interval to ML-dataset pipeline (Motif_pipeline.ipynb)
│   ├── Pysster/             # Pysster model training
│   ├── ClipGPS/             # ClipGPS training/tuning/evaluation
│   ├── MSipNet/             # MSipNet + RNA-FM embeddings
│   └── mutational_scans/    # DeepCLIP and Pysster mutational scanning
└── pycrac_benchmark/        # v1.5.2 vs v2.0.0 runtime benchmarking
```

## Data setup

### Included in this repo

Extract before use:

```bash
tar -xzf data/nab3.tar.gz -C data/
tar -xzf data/ssd1.tar.gz -C data/
```

- **`nab3.tar.gz`** — pyReadCounters GTF output for Nab3: mapped read coordinates, counts and genomic annotations, generated from a Novoalign (`.novo`) file against the R64-1-1.75 annotation.
- **`ssd1.tar.gz`** — pyCalculateFDRs peak GTF for Ssd1 (FDR ≤ 0.05), from Bayne et al., used directly for downstream analyses.

### Not included/download required

Raw sequencing files and reference genomes

**Nab3** [(Esteban-Serna et al., 2025)](https://pubmed.ncbi.nlm.nih.gov/41261861/)
- Raw paired-end FASTQ (demultiplexed, UMI-annotated) and the `.novo` alignment file (generated by the Granneman lab) for GEO:**GSE276517**, replicate 2 of the parental PIC2–GFP/Nab3-HTF strain.
- Reference genome: *S. cerevisiae* R64-1-1 annotation GTF + genome FASTA + chromosome lengths file.

**Ssd1** [(Bayne et al., 2021)](https://pmc.ncbi.nlm.nih.gov/articles/PMC8934651/)
- CRAC data (single-end): GEO accession **GSE159835**.
- Reference genome: *S. cerevisiae* EF4 annotation GTF  + genome FASTA (available from Bayne et al. supplementary materials)

Generate the chromosome-length files with pyCRAC once the FASTA is downloaded:

```bash
pyCalculateChromosomeLengths.py -f <genome.fa> -o <chrom_lengths.txt>
```

> **Note on relative paths:** scripts and notebooks in this repo reference reference/data files via relative paths set up for this exact directory layout. If a script errors with a missing file, check the path variables near the top of the script/notebook and point them at wherever you've placed the downloaded files. The package code (except Pysster) required to run some scripts is not included in these directories and must be cloned from the corresponding GitHub repositories and placed in the expected locations.

## ML Pipeline

**Nab3**

1. Nab3 reads GTF (in `data/nab3.tar.gz`) → pyCRAC `pyCalculateFDRs` (`-r 100`, FDR ≤ 0.05, 100 background iterations) → peak/intervals GTF.
2. `motif_prediction/Data_preparation/Motif_pipeline.ipynb` (50 and 100nt intervals)  → labelled positive/negative FASTA datasets.
3. Train models:
   
   Pysster: `motif_prediction/Pysster/Pysster_fit.py`
   
   ClipGPS:
     1. `motif_prediction/ClipGPS/nab3_data_preparation`
     2. Nab3 data parquet → `motif_prediction/ClipGPS/tuning_pass1.sh`
     3. select best hyperparameters (weight-decay & layers) on validation AUPR and fill in values for tune_pass2.sh
     4. `motif_prediction/ClipGPS/tuning_pass2.sh` (repeat step 3, select best configuration on dropout & learning rate)
     5. `motif_prediction/ClipGPS/custom_nab3_pipeline.sh` (model interpretation plots and mutational scan)

   MSipNet: motif_prediction/MSipNet/pipe.ibynb

**Ssd1**
Starts from the pre-existing `pyCalculateFDRs` output (FDR ≤ 0.05, `data/ssd1.tar.gz`). Steps 2 and 3 apply with the EF4.74 reference and 100nt/300nt intervals; use `custom_ssd1_pipeline.sh` for ClipGPS.

**Mutational scanning:** `motif_prediction/mutational_scans/ClipGPS` (ClipGPS `scan.py`), `.../Pysster` (`pysster_scan_intervals.sh`), and DeepCLIP (deepclip_scan.sh) variant-prediction mode — see individual scripts.
